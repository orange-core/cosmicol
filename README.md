# Cosmicol Limited Website

Responsive multi-page website for Cosmicol Limited, a printing and creative-services business based in Ndola, Zambia.

## Pages
- `index.html` — home, service overview, approach and project CTA
- `services.html` — digital/offset printing, design and branding, signage/large-format printing, promotional materials
- `about.html` — company introduction and working principles
- `contact.html` — contact details, hours, map directions and project enquiry form

## Stack
- Semantic HTML
- Shared responsive CSS in `assets/css/style.css`
- Vanilla JavaScript in `assets/js/main.js`
- No build step or package installation required

## Run locally
Open `index.html` in a browser or serve the repository root with any static web server.

## Contact form behaviour
The quote form validates the required fields and opens a prefilled email draft addressed to `cosmicol.digital@gmail.com`. The site does not transmit or store form submissions. A live server-side form handler can be added when the client approves an email/API destination.

## Business information
Public directory listings identify Cosmicol Limited in Ndola, Zambia, and list digital/offset printing, graphic design, signage, large-format printing and promotional materials. Phone and email are included from public listings. Confirm the address, operating hours, exact service catalogue and contact details with the client before production launch.

## Before launch
- Confirm all business contact details and opening hours with the client.
- Replace any service examples that do not match current offerings.
- Add approved project photographs, print samples and brand assets.
- Test links and form behaviour on mobile and desktop.
- Configure the chosen domain and hosting.
